# AIPulse

Your personal AI tools hub - organize, launch, and track all your AI tools in one place.

![AIPulse Logo](/logo.svg)

## 🚀 What is AIPulse?

AIPulse is a modern web application that helps you discover, organize, and manage all your AI tools in one centralized location. Whether you're a researcher, content creator, developer, or AI enthusiast, AIPulse makes it easy to keep track of your growing collection of AI tools.

## ✨ Features

### Tool Management
- **Organize**: Categorize and organize all your AI tools
- **Quick Launch**: Launch your tools instantly with a single click
- **Smart Search**: Quickly find tools using powerful search functionality
- **Custom Collections**: Create custom collections to group tools by project or category
- **Favorites & Recent**: Quick access to your most-used tools

### Analytics & Insights
- **Usage Tracking**: Track how often you use each tool
- **Analytics Dashboard**: View detailed usage statistics and trends
- **Category Breakdown**: See which tool categories you use most
- **Usage History**: Track your tool usage over time

### User Experience
- **Dark/Light Mode**: Beautiful UI with full dark mode support
- **5 Accent Themes**: Customize with Teal, Purple, Blue, Green, or Orange
- **AI Assistant**: Built-in AI assistant to help you navigate and find tools
- **Keyboard Shortcuts**: Power user shortcuts for quick navigation
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Smooth Animations**: Polished UI with Framer Motion animations

### Privacy & Security
- **Local Storage**: All data stored locally in your browser
- **No Account Required**: No sign-up or login needed
- **Your Data**: You have full control over your data
- **No External Servers**: No data is sent to external servers

## 🎯 Who is AIPulse For?

- **AI Researchers**: Keep track of all your research tools and models
- **Content Creators**: Organize writing, image generation, and video editing tools
- **Developers**: Manage coding assistants, APIs, and development tools
- **Marketers**: Track marketing automation and content generation tools
- **Students**: Organize learning resources and AI study aids
- **AI Enthusiasts**: Discover and explore new AI tools

## 🛠️ Tech Stack

- **Frontend**: React 18 with TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## 📦 Getting Started

### Use the Live Version
Visit [aipulse.dev](https://aipulse-tool.vercel.app) to use AIPulse directly in your browser.

### Run Locally

```bash
# Clone the repository
git clone https://github.com/swiftpersona2-cell/aipulse.git
cd aipulse

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## 🎨 Themes

AIPulse offers 5 beautiful accent themes:
- Default Teal
- Midnight Purple
- Ocean Blue
- Forest Green
- Sunset Orange

Switch themes in Settings → Display.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+K` | Focus search bar |
| `Ctrl+D` | Go to Analytics page |
| `Ctrl+S` | Open Settings |
| `Ctrl+1-4` | Switch view modes |
| `Ctrl+/` | Show all keyboard shortcuts |
